🚲 London Bike Rides Analysis & Visualization

📌 Project Overview

This project analyzes London bike-sharing rides data to uncover trends, seasonality, and the impact of weather and temperature on bike usage.
The analysis combines data cleaning, feature engineering, and interactive visualizations to deliver meaningful insights for decision-making.

The final output is an interactive dashboard with moving averages and heatmaps to clearly show usage patterns over time.

⸻

🎯 Objectives
	•	Analyze bike ride demand over time
	•	Understand seasonal and weather-based patterns
	•	Smooth fluctuations using moving averages
	•	Visualize the relationship between temperature, wind speed, and ride count
	•	Build a business-friendly interactive dashboard

⸻

⸻

📊 Key Features & Visualizations

1️⃣ Time-Series Analysis
	•	Daily bike ride counts over time
	•	20-day moving average to smooth short-term fluctuations
	•	Interactive date range selection

2️⃣ Seasonal Insights
	•	Clear demand variations across Spring, Summer, Autumn, and Winter
	•	Identification of minimum and peak usage periods

3️⃣ Weather Impact Analysis
	•	Mapping weather codes to readable labels:
	•	Clear
	•	Scattered Cloud
	•	Broken Cloud
	•	Rain
	•	Snowfall
	•	Analysis of how weather conditions influence ride volume

4️⃣ Temperature vs Wind Heatmap
	•	Heatmap showing total rides by:
	•	Temperature (°C)
	•	Wind speed (kph)
	•	Helps identify optimal weather conditions for maximum bike usage

⸻

🧠 Key Insights
	•	Bike rides increase significantly in moderate temperatures
	•	Extreme cold and high wind speeds reduce usage
	•	Summer and clear-weather days show peak demand
	•	Moving averages help identify long-term trends beyond daily noise
